# Enterprise GenAI Assistant

A local, open-source GenAI platform for enterprise content generation,
code generation, SAP ABAP naming standardization, and SAP ABAP
code optimization.

## Planned Features

- Text generation
- Email generation
- Code generation
- Coding standards RAG
- SAP ABAP naming convention validation
- SAP ABAP code optimization
- Hybrid BM25 + dense retrieval
- Cross-encoder reranking
- Local LLM inference
- Qdrant vector database
- Docker deployment

## Technology

- Python
- Flask
- Hugging Face
- Qdrant
- BM25
- Docker
- Git/GitHub
